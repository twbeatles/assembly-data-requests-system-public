[안내] 신규 국회·대외기관 요구자료 간편 등록 폴더
================================================================================
새롭게 수신된 한글(HWP, HWPX), 엑셀(XLSX), PDF 문서를 이 폴더에 마우스로 끌어다 넣으신 후,
다음 중 편하신 방법 하나를 실행하시면 5초 안에 DB와 웹 대시보드가 자동으로 갱신됩니다!

[방법 1] '00_새자료_추가_및_DB동기화.bat' 더블클릭 (가장 간편)
[방법 2] '자료요구_통합검색.exe' 실행 후 상단 [➕ 새 자료 추가 / DB 갱신] 버튼 클릭
[방법 3] '자료요구_통합검색_대시보드.html' 열기 전 배치파일 실행

* 등록이 완료되면 파일은 연도별 폴더(예: 2026년 폴더)로 자동 정리되거나 원본 상태를 유지하며
  '자료요구_통합검색_대시보드.html', '국회_대외기관_자료요구_통합DB.xlsx', 'data_requests.db'에
  즉시 반영됩니다.
