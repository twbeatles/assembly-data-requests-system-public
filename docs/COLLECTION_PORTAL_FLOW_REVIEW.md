# 취합 포털 업무 흐름 점검과 공문서 기준 보완

점검 2026-11-24 · 대상: `scripts/collection_portal` (포털 DB 스키마 5 → 7: 6은 공문·소관 조정, 7은 질의 단위 배정)

요구 건 등록부터 대장 반영 확인까지 화면과 서버 코드를 단계별로 따라가며, 실제 국회 요구자료 취합 업무에서 막히는 지점과 공문서 작성 기준에서 빠진 항목을 찾았다. 확인된 공백은 이번 작업에서 구현하고, 기관 시스템이나 법령 해석이 필요한 항목은 남은 과제로 분리했다.

## 1. 흐름 점검 결과

| 단계 | 확인한 동작 | 발견한 공백 | 조치 |
| --- | --- | --- | --- |
| 등록 | 제목·요구자·요구 내용·대외 마감·대장 ID·양식 | 요구 공문의 문서번호·접수일·수신(요구 기관)·요구 근거가 없어 회신 공문에 "관련" 항목을 쓸 수 없다. | 4개 항목 추가, 접수일이 대외 마감보다 늦으면 거부 |

| 마감 표시 | 지난 경우 "지연" | 임박한 마감이 보이지 않고 지연 일수가 없다. | "오늘 마감", "마감 D-1·D-2", "지연 n일", 취합팀 카드에 지연 부서 수 |

## 2. 적용한 공문서 기준

| 기준 | 내용 | 포털 반영 |
| --- | --- | --- |
| 「행정업무의 운영 및 혁신에 관한 규정 시행규칙」 제2조 | 본문은 제목·내용·붙임으로 구성, 항목 기호는 1., 가., 1), 가), (1), (가), ①, ㉮ 순서, 본문 끝에 "끝" 표시 | 초안은 `수신 / (경유) / 제목 / 1. 2. … / 붙임`으로 쓴다. 붙임 1건은 번호 없이, 여러 건은 `1. 2.`로 쓰고 마지막 붙임 뒤 두 칸 띄어 "끝."을 붙인다. 붙임이 없으면 본문 끝에 붙인다. |
| 행정업무운영 편람의 날짜 표기 관행 | 연·월·일 글자를 생략하고 온점으로 표시(`2026. 11. 24.`) | 공문 초안, 요구 건 접수일, 제출본 기준일 표시 |
| 「공공기관의 정보공개에 관한 법률」 제9조제1항 | 비공개 대상 정보 제1~8호 | 부분공개·비공개 제출 시 해당 호와 구체적 사유 필수. 공문 초안에 "「공공기관의 정보공개에 관한 법률」 제9조제1항제○호에 해당하여 비공개를 요청" 문구를 넣는다. |
| 개인정보 포함 자료 | 요구 목적 범위의 제공과 목적 외 이용 제한 | 개인정보 포함 표시, 확정 전 책임자 확인, 공문 초안에 목적 외 이용 자제 요청 문구 |

공문 초안은 기안 보조 자료다. 문서번호·시행일자·발신명의·결재는 기관 전자문서시스템에서 처리하며, 초안 끝에 이를 안내한다. 요구 근거(예: 「국회법」 제128조)는 입력값을 그대로 쓰고 포털이 근거 법령을 판단하지 않는다.

## 4. 질의 단위 배정 (스키마 7)

국회 요구자료는 한 공문에 여러 질의가 들어 있고, 질의마다 담당 부서가 다르거나 한 질의를 여러 부서가 함께 답하는 경우가 많다. 종전에는 부서별 답변 본문 하나만 받아 취합팀이 질의 순서로 다시 맞춰야 했다.

| 항목 | 동작 |
| --- | --- |
| 질의 등록 | 취합팀이 요구 건 화면에서 질의를 한 줄에 하나씩 붙여 넣는다. 앞 번호(`1.`, `2)`, `가.`, `①`, `-`)는 떼고 포털 번호를 쓴다. 답변이 제출되지 않은 질의만 삭제할 수 있다. |
| 답변 부서 지정 | 질의마다 부서를 체크한다. 여러 부서를 고르면 공동 답변이고, 질의마다 다른 부서를 고를 수 있다. 아직 배정되지 않은 부서는 자동으로 배정되고(내부 마감 지정), 취소된 배정은 되살아난다. |
| 부서 화면 | 자기 배정에 연결된 질의만 보이고 질의별 입력칸에 답한다. 공동 배정된 다른 부서의 이름·답변은 보이지 않는다. 배정된 질의를 모두 답하거나 배정 전체를 "해당 없음"으로 제출해야 한다. 질의 외 의견은 본문에 쓴다. |
| 배정 변경 | 이미 제출·승인한 부서에 질의를 더하면 그 부서는 보완 요청으로 돌아가고, 이전 답변·첨부·메타가 초안에 채워진다. 질의 배정을 해제하면 그 질의의 초안 답변도 지워지고 부서에 공지된다. |
| 취합 | 취합 초안과 ZIP의 `질의별답변.txt`는 질의 순서로 모인다. 공동 답변은 `○ 부서: 답변`으로 나란히 두고 문구 통합은 취합팀이 한다. 승인된 답변이 없는 질의가 있으면 최종 확정에 예외 사유가 필요하고, 확정 기록에 "미답변 질의 n"이 남는다. |
| 검색 | 취합팀은 질의 문구와 제출된 질의별 답변을, 부서는 자기 배정의 질의·초안·제출 답변만 검색한다. |
| 기존 요구 건 | 질의를 등록하지 않은 요구 건은 종전처럼 부서별 본문 하나로 취합한다. |
